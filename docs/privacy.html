TTZip 隐私政策 (Privacy Policy)

最后修订生效日期：2026年8月18日

1. 核心隐私承诺

TTZip 是一款运行在您本地 Mac 计算机上的原生归档与解压工具软件。我们坚信用户的隐私权不可侵犯，因此 TTZip 对所有文件处理遵循“100% 本地运算、零文件内容上传、零行为遥测追踪”的隐私安全准则。

2. 文件处理与归档操作（100% 本地执行）

  • 无个人信息收集与遥测：TTZip 不收集您的姓名、电子邮箱、设备标识符或使用行为统计数据，未集成任何第三方统计、遥测或广告分析 SDK。
  • 无文件内容或元数据上传：您压缩、解压、加密或预览的所有文件、文件名、目录结构、密码及哈希校验，全部在您本地内存与磁盘中由原生 Rust + C/C++ 微内核引擎与受沙盒隔离的本地进程处理，绝不上传至任何外部服务器。

3. 分发渠道与更新检查说明

不同分发渠道的构建版本在网络请求行为上存在明确区分：

  • Mac App Store 与 Steam 商店版本：不包含任何第三方更新框架（完全移除 Sparkle），应用自身不发起任何软件更新网络请求。版本更新与购买验证分别由 Apple Mac App Store 与 Valve Steam 平台按各自隐私规范独立处理。
  • Direct（官网 / GitHub Release）与社区版本：内置开源更新框架 Sparkle 2，仅用于向 GitHub 官方托管源（raw.githubusercontent.com / github.com）查询经 Ed25519 数字签名认证的更新清单（appcast.xml）及下载更新包。许可证激活校验采用本地离线 Ed25519 公钥签名算法，不发起联网验证。

4. 系统权限、沙盒与 Required Reason APIs 说明

为了在 macOS App Sandbox 沙盒规范下完成归档管理与本地预览，TTZip 仅按实际功能需要调用以下系统权限与接口：

  • 用户选择的文件与常用目录读写权限：通过 NSOpenPanel / NSSavePanel、拖拽授权及标准用户目录权限（Downloads / Documents / Desktop / Pictures / Movies / Music 及外置移动存储卷），支持工作区浏览、跨目录压缩与原位解压。
  • 安全作用域书签 (Security-Scoped Bookmarks)：用于在您授权后持久化保存已固定的工作区文件夹与最近访问路径，避免重启应用后重复弹窗授权。
  • 本地 WebKit 预览渲染 (com.apple.security.network.client)：仅用于满足 macOS WKWebView 进程外渲染服务（com.apple.WebKit.WebContent XPC 进程）在 App Sandbox 下的系统级进程初始化要求：其中 Quick Look 扩展（QuickLookPreviewViewController）通过 loadHTMLString(..., baseURL: nil) 渲染归档结构预览；主应用富文档预览（HTMLWebRichPreviewView、EPUBNativeWKWebView）使用本地文件/归档资源并受 TTWebPreviewContentPolicy 导航与离线内容策略约束，阻断外部网络请求。
  • Apple Required Reason APIs 声明：
    • NSPrivacyAccessedAPICategoryFileTimestamp (C617.1, 3B52.1)：在浏览、打包或解压归档时读取与还原文件的创建和修改时间戳。
    • NSPrivacyAccessedAPICategoryUserDefaults (CA92.1, 1C8F.1)：读写应用自身偏好设置（CA92.1）及主应用与 Finder Sync / Quick Look 扩展共享的 App Group (group.com.metastudyline.ttzip) 配置（1C8F.1）。
    • NSPrivacyAccessedAPICategoryDiskSpace (E174.1, 85F4.1)：在工作区存储检查器中向用户展示磁盘卷状态，并在写入/解压前检查目标卷挂载属性与可用空间以防磁盘写满。
    • NSPrivacyAccessedAPICategorySystemBootTime (35F9.1)：使用单调时钟（systemUptime / mach_absolute_time）测量应用内操作耗时、权限缓存 TTL 及主线程卡顿诊断看门狗时间间隔。

5. 密码保险箱安全性

您保存在密码保险箱中的解压密码均采用硬件级 AES-256 加密与 600,000 轮 OWASP 强化 PBKDF2-SHA256 派生存储于您本地的 Keychain 与安全存储区。密码在内存使用完毕后均通过 volatile 指针执行物理强制清零（防 Dead-Store 消除），绝无泄露风险。
