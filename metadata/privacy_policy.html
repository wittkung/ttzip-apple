TTZip Privacy Policy

Last Updated: August 25, 2026

Your privacy is our utmost priority. TTZip is designed from the ground up as a native, local-first utility for macOS.

1. File Processing & Archive Operations (100% Local On-Device)

TTZip does not collect, transmit, store, or sell any personal data, hardware fingerprints, file contents, filenames, passwords, or usage telemetry.

  • No Analytics or Tracking SDKs: No edition of TTZip includes third-party analytics, crash telemetry, or advertising SDKs.
  • 100% On-Device Execution: All archive compression, decompression, cryptographic hashing, and in-archive Quick Look previews execute entirely on your Mac using our native Rust and C/C++ microkernel and sandboxed local helpers.
  • Zero Cloud Upload: Your files, directory structures, and archive metadata never leave your device.

2. Channel-Specific Network & Update Behavior

  • Mac App Store & Steam Editions: Contain no third-party updater framework and make zero software update network requests. Application updates and purchase receipts are managed exclusively by Apple (Mac App Store) and Valve (Steam) under their respective privacy policies.
  • Direct / GitHub Release Edition: Uses Sparkle 2 solely to check raw.githubusercontent.com / github.com for Ed25519-signed appcast.xml release updates when automatic or manual update checks run. Pro license key verification is evaluated 100% offline using Ed25519 public-key cryptography with zero network calls.

3. Cryptographic Security, Sandbox & Required Reason APIs

  • Password Vault & Memory Zeroization: Archive passwords stored in the local Vault are protected via Apple Keychain and AES-256 with 600,000-round PBKDF2-HMAC-SHA256 key derivation. Transient password buffers in RAM are actively zeroized via volatile pointers immediately after cryptographic operations complete.
  • App Sandbox & Required Reason APIs: File system access is scoped to user-selected files, authorized workspace folders, and security-scoped bookmarks. System APIs for file timestamps (C617.1, 3B52.1), app/group preferences (CA92.1, 1C8F.1), volume disk space & mount status (E174.1, 85F4.1), and monotonic elapsed timers (35F9.1) are used strictly for local archiving, UI display, and hang diagnostics.
